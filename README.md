# evenus.app

The website for **EvenUS** — a mobile app for couples that measures how fairly
money, time and mental load are shared in a household, then suggests one task to
swap each week.

Static HTML, generated by one Node script. No framework, no client-side
JavaScript, no analytics, no cookie banner, and one webfont request. That is a
constraint rather than minimalism for its own sake: the pages that matter most
here are the privacy policy and the account-deletion page, both app stores check
that they load, and a page that needs a bundler to render is a page that can
fail to render.

```bash
node src/build.mjs      # -> dist/
npm run serve           # build, then serve dist/ on :8080
```

## What it builds

| | |
|---|---|
| `/` | Homepage |
| `/blog/` + 115 posts | Recovered from the Internet Archive — see below |
| `/support/` | Help. **Required** — App Store Connect validates a support URL |
| `/privacy/`, `/terms/`, `/disclaimer/` | Legal |
| `/delete-account/` | ⚠️ Google Play requires this to load **for someone with no account** |
| `sitemap.xml`, `robots.txt`, `404.html`, `favicon.svg` | |

## Layout

```
src/
  build.mjs              the whole build
  site/layout.mjs        the page shell, palette, nav, footer
  site/markdown.mjs      the markdown subset src/legal uses
  site/wordpress.mjs     pulls prose out of the recovered pages
  legal/*.md             ← EDIT THESE. dist/ is generated.
  recovered/blog/*.html  115 archived posts, the blog's source
dist/                    generated output; not committed
```

## Before this goes live

Five placeholders remain in `src/legal/*.md` — `[COMPANY NAME]`,
`[COMPANY ADDRESS]`, `[CONTACT EMAIL]`, `[JURISDICTION]`, `[WEBSITE]`. The build
prints every one that is still present and will keep printing them until they
are replaced. **Both app stores gate submission on these pages**, so this is not
cosmetic.

## Hosting

Pushing to `main` builds and deploys to GitHub Pages automatically.

`BASE_PATH` is the thing to understand. A GitHub **project** site is served from
`/<repo>/`, not from `/`, so every root-relative link 404s without it — and that
breakage only appears after deploying. The workflow sets
`BASE_PATH=/evenus-website`; building with no `BASE_PATH` produces the
root-relative version for a custom domain.

To move to **evenus.app**: point DNS at GitHub Pages, set the custom domain in
*Settings → Pages*, and drop the `BASE_PATH` line from the workflow.

### Vercel

`vercel.json` carries the build command and output directory.

⚠️ **Without it Vercel serves 404s for everything**, and the reason is easy to
miss: `dist/` is gitignored, so there is no `index.html` in the repository for a
zero-config deploy to find. Vercel has to be told to run the build.

Vercel serves from the domain root, so **no `BASE_PATH`** — the default,
root-relative build is the correct one there. Do not copy the workflow's
`BASE_PATH` into Vercel's environment variables; it would prefix every link with
`/evenus-website` and break the whole site.

⚠️ **`.app` is on the browser HSTS preload list.** Every `.app` domain must serve
valid HTTPS — browsers refuse plain HTTP outright, with no click-through. Tick
*Enforce HTTPS* once the certificate is issued.

## The WordPress import

The original site was WordPress with Elementor and was deleted at the host. The
domain survived; the files did not. The Internet Archive had crawled it, so the
writing survived even though the theme, the stylesheets and every image did not.

`src/site/wordpress.mjs` imports **only the prose**. It is an allow-list, not a
strip-list, and that distinction is the whole design: removing the tags you
happened to notice leaves the ones you did not, which is exactly how a WordPress
footprint survives a migration. It finds the post body, then keeps only semantic
tags and only `href` on links. Every class, id, style, `data-*` attribute and
wrapper div is gone because it was never let through.

**The build asserts it.** If `wp-content`, `elementor`, `googletagmanager` or
nine others appear anywhere in the output, the build fails rather than printing a
warning nobody reads.

Images were never archived, so posts are text-only. For 115 posts that is the
half worth keeping.
